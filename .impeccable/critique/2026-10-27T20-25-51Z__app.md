## Design specificity verdict
Design review: a generic Tailwind SaaS dashboard (indigo, Inter, bordered cards, colored icon chips, bar chart + donut). The private, local-first positioning is invisible. Color collisions: emerald means both Bills and "spending down"; sky means both Transportation and "This month". The Daily average card uses a trending-up icon.
Automated scan: the source scan found 0, but contrast/size rules can't run on source files, so that's an undercount. The browser scan found 4 low-contrast warnings, all slate-400 (#94a3b8) on white at 2.6:1: the search placeholder (ExpenseFiltersBar.tsx:15), the amount and description placeholders (ExpenseForm.tsx:35), and the 0/100 counter (ExpenseForm.tsx:185). The design review also flagged icon buttons in the same color as failing the 3:1 non-text rule. Placeholders with visible labels are advisory; the counter is a real failure.

## What's working
1. Native dialog handling: focus lands on Amount, returns to the trigger, Esc/outside click closes.
2. Form validation: errors on blur or submit, focus jumps to the first error, amount reformats, numeric keypad on phones, category icon tiles.
3. Expenses summary bar: live, announced to screen readers; filtered-empty state has its own Clear filters.

## Priority issues
1. [P1] Local-first positioning invisible; backup is one-way. Fix: always-visible "Stored only in this browser · Last export" indicator, privacy line in headers, CSV import. Commands: onboard, clarify, harden.
2. [P1] Delete all under-protected and misplaced (beside Export, first action on mobile, no undo). Fix: move into a Data menu, Export button inside the confirmation, Undo snapshot or type-to-confirm. Command: harden.
3. [P2] Contrast and timing accessibility: slate-400 text and icons at 2.6:1; Undo toast disappears after 6s with no pause; nested announcement regions; category error not linked. Fix: slate-500+, pause timer on hover/focus, remove inner role=status, link the error. Commands: audit, polish.
4. [P2] Mobile layout: summary cards about 1.5 screens; filters take about 60% of the first screen; Add at top right; chips 24px; row targets 32px and 4px apart; no sorting. Fix: 2x2 summary grid, collapsible Filters (n), bottom Add, tap row to edit, sort dropdown. Commands: adapt, layout.
5. [P2] Generic visual language. Fix: drop the icon chips, make "This month" the headline number, keep emerald/red for meaning, add one product-specific detail (typeface for amounts or a "local" mark). Commands: quieter, colorize, typeset.

## Minor observations
